# Stream Chat Overlay

## Overview

The **Chat Settings** allow you to display live messages from your YouTube or Twitch audience directly on your phone's screen while you game. This ensures you never miss a message from your community, even without a second monitor.

---

## 🚀 Setting Up Chat

### Prerequisite: Floating Bubble
To see the chat overlay, you must first enable the **Floating Control Bubble** in the Overlay Settings. 
- The chat interface is integrated into the floating dashboard for quick and easy access during gameplay.

---

## 🎨 Customizing the Look

Make the chat fit your stream's aesthetic with deep customization options.

### 1. Typography & Size
- **Font Size**: Choose between **Small**, **Medium**, or **Big** text.
- **History Limit**: Control how many messages are kept in the scroll history (50, 100, or 200). 
    - *Performance Tip: Keeping the limit at 50 or 100 is recommended for mid-range devices to prevent lag.*

### 2. Name & Message Styling
- **Sender Name Style**:
    - **Random Colors**: Every viewer gets a unique, vibrant color automatically.
    - **Custom Color**: Pick a specific Hex color (e.g., `#00E5FF`) for all usernames.
- **Message Text Style**:
    - **Random Text Colors**: Make the chat look "Rainbow" style with colorful messages.
    - **Custom Color**: Keep the chat clean with a single consistent color for all message text.

---

## ⚡ Performance Optimization

LiveLens uses a background processing engine to fetch chat messages without interrupting your game's CPU cycles. However, if you experience frame drops:
1. Reduce the **Chat History Limit** to 50.
2. Disable **Random Colors** for names and messages.

---

## Chat Settings Summary

| Feature | Description |
|---|---|
| Floating Integration | Requires the Control Bubble to be active |
| History Limit | Saves up to 200 messages in the scrollback |
| Style Modes | Switch between Random (Rainbow) or Custom solid colors |
| Multi-Platform | Supports chat from linked YouTube and Twitch accounts |
