# What is LiveLens?

## Overview

LiveLens is a mobile streaming and recording application designed to give mobile creators more freedom and control over their streaming setup.

It is built around an **OBS-style, empty-canvas workflow**, where users can create their own layouts and scenes instead of being restricted to predefined layouts or limited templates.

LiveLens is developed by **Bycon Studio**, with development led by **Arpan**, a solo developer and streamer with several years of personal streaming experience.

---

## Why LiveLens Was Created

LiveLens was created from a practical problem experienced firsthand by its developer.

The developer has been streaming for several years and has experienced the limitations of mobile streaming applications directly. This experience highlighted several recurring problems in the mobile streaming ecosystem:

- Limited control over streaming layouts.
- Limited source support.
- Restrictions on how creators can build their scenes.
- Mobile hardware not being given enough flexibility for advanced streaming workflows.
- Watermarks.
- Advertisements.
- Subscription-based features.
- Account requirements for using streaming applications.
- Limited customization compared with desktop streaming software.

Modern smartphones can provide considerably more CPU and GPU performance than the typical mobile streaming workflows make use of. LiveLens was created with the goal of making better use of the hardware available on modern Android devices while giving creators significantly more control over their production setup.

---

## The Core Idea

The central idea behind LiveLens is **freedom**.

Instead of forcing users to choose from predefined layouts, LiveLens provides an empty canvas where creators can build their own streaming scenes.

Users can decide:

- What sources they want to use.
- Where each source should be placed.
- How their layout should look.
- How many scenes they want to create.
- How their scenes should be organized.

The goal is to make the phone act more like a flexible streaming production system rather than a simplified mobile streaming application.

> **"Freedom in your pocket, not a smaller version of a locked-down tool."**

This philosophy is one of the core ideas behind LiveLens.

---

## Empty Canvas

LiveLens uses an empty-canvas approach to scene creation.

Rather than providing a fixed layout that the user has to adapt to, LiveLens allows the user to build a layout from the ground up.

A creator can design a scene according to their own requirements, whether they are creating:

- A gaming layout.
- A vertical streaming layout.
- A VTuber layout.
- A camera-focused layout.
- A starting-soon scene.
- A custom content-creation layout.
- Or any other arrangement they want to create.

Users can also create multiple scenes and organize their streaming workflow around them.

There is no fixed number of scenes that a user is required to use.

---

## Sources

LiveLens supports multiple types of sources that can be combined inside scenes.

Currently supported sources include:

- **Screen Capture**
- **Camera**
- **Image**
- **Text**
- **GIF**
- **Video**
- **Web**
- **VTuber**
- **UVC (Beta)**

The source system is designed to allow different types of content to be combined into a single custom scene.

This allows creators to build more complex streaming layouts directly on Android instead of relying on a separate desktop production setup.

> Source availability and performance can depend on the device and the specific source configuration.

For detailed information about each source, see the individual source documentation.

---

## Scenes

LiveLens allows users to create as many scenes as they need for their own workflow.

Scenes can be designed independently and can contain different combinations of sources.

For example, a creator could have separate scenes for:

- Starting Soon
- Main Gameplay
- BRB
- Ending
- Just Chatting
- VTuber content
- Different games
- Different streaming layouts

LiveLens also supports **scene import and export**, allowing scenes to be transferred or shared instead of requiring users to recreate them manually.

---

## Streaming and Recording

LiveLens is designed for both **live streaming and local recording**.

Users can configure their streaming workflow according to their requirements and use the application as a mobile production environment.

LiveLens also supports custom RTMP streaming, giving users the option to stream to platforms that are not directly integrated into the application.

---

## Streaming Platform Login

LiveLens does not require users to create a LiveLens account just to use the application.

However, some streaming-platform features may require authentication with the relevant platform.

For example, if a user wants to use platform-specific functionality such as directly creating a stream schedule through an integrated platform, they may need to log in to that platform.

Users who do not want to use platform integration can use the **Custom RTMP** option where supported.

This distinction is important:

> **LiveLens itself does not require an account for normal application usage, but individual streaming platforms may require their own authentication.**

---

## No Forced Account

One of the design decisions behind LiveLens is to avoid forcing users to create an account simply to use the application.

Many large streaming applications require users to create an account and log in before they can use the application's core functionality.

LiveLens takes a different approach.

The application is designed so that users can use its core streaming and production features without having to create a LiveLens account.

---

## No Ads, No Watermark, No Subscription

LiveLens is currently designed around three important principles:

- **No advertisements**
- **No watermark**
- **No subscription requirement**

The purpose of this approach is to allow creators to use their streaming setup without having the application itself interfere with their content or workflow.

LiveLens is intended to remain focused on the creator rather than placing restrictions around the creator's streaming output.

---

## Privacy-First Philosophy

Privacy is an important part of the LiveLens design philosophy.

The application is designed to avoid unnecessary account requirements and unnecessary barriers to using the application.

The developer intends to maintain this privacy-first approach as LiveLens continues to evolve.

However, future monetization cannot be guaranteed indefinitely.

The long-term goal is that if LiveLens receives enough community support, the application can continue without introducing paid items.

The project's current philosophy is therefore:

> Keep the core experience free, open, and focused on user freedom, while allowing the project to remain sustainable through community support.

---

## Community Support

LiveLens is developed independently by Bycon Studio.

Because LiveLens is developed by a solo developer, community support and feedback are important to the project's continued development.

User feedback can influence:

- New features.
- Improvements to existing features.
- Bug fixes.
- Compatibility improvements.
- Workflow improvements.

The goal is to continue improving LiveLens based on the needs of real creators while maintaining its core philosophy of freedom and user control.

## Who is LiveLens For?

LiveLens is primarily designed for creators who want more control over their mobile streaming workflow.

It can be useful for:

- Mobile streamers.
- Gaming streamers.
- VTubers.
- Content creators.
- Creators who want custom streaming layouts.
- Creators who want an OBS-style workflow on Android.
- Users who want to stream without a watermark.
- Users who do not want to subscribe to use core streaming features.
- Users who want to create their own scenes instead of using predefined layouts.

---

## What Makes LiveLens Different?

LiveLens focuses on several ideas that are often limited or separated across mobile streaming applications:

### Custom production workflow

Users build their own scenes instead of being restricted to predefined layouts.

### Multiple source types

LiveLens brings different source types together in a single mobile streaming environment, including video, GIF, web, VTuber, screen capture, camera, image, and text sources.

### Empty-canvas design

The user starts with a canvas rather than being forced into a predefined design.

### No forced LiveLens account

Core application usage does not require creating a LiveLens account.

### No watermark

LiveLens does not currently place a watermark on the creator's stream.

### No advertisements

The application is currently designed without advertisements.

### No subscription

Core LiveLens functionality is currently available without a subscription.

### Custom RTMP

Users can use custom RTMP when they want to stream without relying on a specific integrated platform.

---

## Development Philosophy

LiveLens is built around the idea that a mobile device should not automatically mean a heavily restricted streaming experience.

The goal is not simply to create a smaller version of existing desktop streaming software.

Instead, LiveLens aims to provide as much flexibility as modern Android hardware can reasonably support while remaining practical for mobile creators.

The project prioritizes:

- Freedom.
- Customization.
- Creator control.
- Privacy.
- Hardware utilization.
- Flexible scene creation.
- Broad source support.
- A mobile-first workflow.
